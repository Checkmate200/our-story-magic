# Our Love Story

A keepsake anniversary website — "Two Whole Years, You & Me."

## Tech Stack

- **Framework**: TanStack Start (React SSR with Nitro)
- **Styling**: TailwindCSS v4
- **Build**: Vite
- **Hosting**: Vercel (serverless)

## Development

```sh
npm install
npm run dev
```

## Production Build

```sh
npm run build
npm run preview
```
